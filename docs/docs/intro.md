# Photo Studio Website

Веб-сайт візитівка для фотостудії з можливістю бронювання.
## Технології
- Frontend: React.js
- Backend: Express.js
- Database: MySQL

## Конфігурація
### Frontend
cd frontend
npm install
npm run dev

### Backend
cd backend
npm install
npm run dev
